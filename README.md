# Peak Post Purchase Survey

A Shopify App Store app that lets merchants ask customers short survey questions after they buy, on the Thank you and Order status pages.

**Live listing:** https://apps.shopify.com/survey-3
**My role:** Shopify App Developer. I built the whole app.

## What it does

- Drag-and-drop survey builder with choice, dropdown, text, email, name and phone fields
- Shows surveys on the Thank you page, the Order status page, or both
- Turns survey opt-ins into Shopify email subscribers with GDPR consent records
- Analytics dashboard with response trends, completion and drop-off rates
- Browse every answer per survey and export responses to CSV
- English and German

## Stack

Shopify app, React, Node.js, JavaScript

Source code is private (client project).
